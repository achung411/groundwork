Import fictional transactions

Choose sample-data/transactions-2026-10.csv, or another synthetic file using the same five columns. UTF-8 CSV only; 2 MB maximum. Invalid rows block the entire import.

CSV format and duplicate rules

Required columns: transaction_id,account_label,posted_date,description,amount. Each row needs an identifier, an existing fictional account label, a YYYY-MM-DD posted date, a description, and a positive USD amount with at most two decimal places.

Identical files are skipped. A repeated identifier on the same property (including across its label aliases) is skipped if all transaction details match; conflicting details block the entire file. The same identifier on a different property is allowed. Configure accepted labels from the property’s lease records; matching ignores capitalization and surrounding spaces. Amount alone never establishes a duplicate or a payment match.
